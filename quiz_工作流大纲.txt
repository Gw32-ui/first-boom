【项目目标】
将本地课件（PDF/DOCX/JPG）解析后生成知识题库，
通过 Web 网页 + MCP 两种方式在本地交互答题，
答题结束后罗列错题并解析（题库自带解题步骤优先，原文引用兜底），
支持按考试模板组卷。
本期范围：完全本地运行，不做内网穿透、不做云部署。

【关键技术栈】
Python 3.12+ / uv / FastAPI / SQLite /
pdfplumber / python-docx / pix2text(公式识别) /
pytesseract+Tesseract-OCR(图片OCR) / MathJax(公式渲染)
sentence-transformers / faiss-cpu (新增 2026-08-17)

【数据存储设计】（重要）
- 所有数据存在本地硬盘，永久保存，关机不丢
  1. 课件原件        → materials/ 文件夹
  2. 整个题库(全科目) → data/questions.db 单文件
  3. 程序本体(本地网站)→ quiz-platform/ 代码文件夹
  4. 学习记录/错题本   → 同写在 questions.db
  5. 向量索引文件      → data/embedding.index + questions_meta.json (新增)
- 实时答题靠硬盘：答题时从磁盘读题 → 网页显示 → 答完写回磁盘，
  RAM 只临时放"当前这份试卷"(几十KB)，答完即释放
- AI 对话/MCP 交互：本地 Python 程序 + 磁盘题库，不联网；
  LLM 智能讲解(后续迭代)跑在云端，本地不存 AI 数据
- 换科目设计：题库表结构带 subject(科目)/course(课程) 字段，
  换科目=同一库里切换分区，删除科目=按字段批量删记录+删课件文件，
  备份=复制 questions.db 到网盘/优盘
- 空间占用：题库纯文本极小(1万题≈20MB)，源课件解析后建议归档网盘
- 对比理解：MySQL是服务器软件(数据藏数据目录)，SQLite是单文件
  数据库(即 data/questions.db)，复制该文件=备份全部题库
